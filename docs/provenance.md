# Provenance and sharing precautions

Gridworld in this class closely resembles the Berkeley CS188 educational
Gridworld/Pacman code (e.g., BookGrid, BridgeGrid, DiscountGrid, MazeGrid,
CLI flags and filenames). Compare:

https://github.com/manfreddiaz/berkeley-cs-188/blob/master/project-3/reinforcement/gridworld.py
https://ai.berkeley.edu/

A GitHub-hosted version of that code expressly requires educational use,
attribution, notice retention, and not publishing solutions. The supplied
Tübingen archive is modified relative to Berkeley's implementation, and no
independent license verification was performed for this class version. Keep
this repository private and ask instructors before publishing solutions or
redistributing the provided starter code. Do not presume a public license.

No source homework sheets, solution ZIP archives, or submitted PDFs are bundled.
